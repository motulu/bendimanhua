本地动漫作品管理软件 v8.0.0 — 产品介绍

产品概览
--------

本地动漫作品管理软件是一款专为动漫、游戏、影视爱好者设计的本地媒体库管理系统。
无需联网，数据全部保存在本地硬盘，支持多种作品分类的精细化管理，从作品信息、
人物档案、标签体系到收藏整理，提供一站式的本地资源管理体验。

核心设计理念：
  本地优先、数据可控、分类精细、功能完整。所有数据以 JSON 格式存储，可随时备份、
  迁移和手动编辑，不会被封闭格式锁定。

14 大分类体系
-------------

涵盖动漫、游戏、影视等多种媒介类型，每个分类拥有独立的字段配置，贴合不同类型
作品的信息管理需求。

  ▪ 番剧       ▪ 漫画       ▪ 电视剧
  ▪ 短剧       ▪ 漫剧       ▪ 动态漫
  ▪ 游戏       ▪ MMD        ▪ 3D 作品
  ▪ 2D 作品    ▪ AV         ▪ MV
  ▪ 声音作品    ▪ 网站存储柜

核心功能
--------

【作品管理】
  支持作品的增删改查、海报封面、详细信息录入、进度追踪、相关作品关联等完整功能。

【人物库】
  独立的人物档案管理，包含基本信息、人物介绍、头像相册、人物关系、出场作品关联等。

【标签库】
  支持作品标签与人物标签两套体系，可按分组管理，编辑时智能联想补全，标签库统一维护。

【收藏夹】
  自定义收藏夹分组，可跨分类收藏作品，支持收藏夹介绍、右键编辑删除、作品批量添加移除。

【回收站】
  删除的作品进入回收站，可随时恢复。支持过期自动清理、批量彻底删除、清空回收站等操作。

【数据统计】
  按分类、进度状态、标签、地区等多维度统计作品数量，可视化展示你的收藏构成。

【导入导出】
  支持 ZIP 格式完整数据备份，可导入导出作品、人物、标签、收藏夹等全部数据，便于备份和迁移。

【漫画阅读器】
  内置漫画阅读器，支持垂直滚动阅读模式，自动消除图片缝隙，阅读体验流畅。

作品管理
--------

每个分类的作品都拥有丰富的字段配置，可根据类型特点记录详细信息。所有字段支持
自定义扩展，满足不同用户的个性化管理需求。

通用字段：
  ▪ 作品名称（中/原/别名）
  ▪ 海报封面与比例设置
  ▪ 作品简介与亮点/缺点
  ▪ 作品标签（分组管理）
  ▪ 进度状态追踪
  ▪ 评分与审查备注
  ▪ 相关作品关联
  ▪ 链接与附件资源
  ▪ 自定义字段扩展

人物关联：
  ▪ 作品关联多位出场人物
  ▪ 内联编辑人物信息
  ▪ 从人物库快速选择添加
  ▪ 人物关系与角色标注
  ▪ 点击人物跳转详情页
  ▪ 双向关联自动同步

人物库
------

独立的人物档案管理系统，记录你喜欢的角色信息。每个人物拥有独立的档案页面，
支持丰富的信息字段和关系网络。

  ▪ 人物基本信息：姓名、别称、性别、年龄、身高、三围、生日、星座、血型等
  ▪ 人物介绍：详细的人物背景故事和设定描述
  ▪ 头像相册：多张人物图片，支持封面设置和点击大图预览
  ▪ 人物关系：建立人物之间的关系网络（朋友、恋人、家人、敌对、师徒等）
  ▪ 出场作品：关联该人物出场的所有作品，支持从作品库快速选择
  ▪ 人物标签：独立的人物标签体系，按分组管理，支持智能联想
  ▪ 自定义字段：可根据需要添加额外的人物信息字段

标签系统
--------

双标签库设计，作品标签与人物标签相互独立，均支持分组管理。编辑时提供智能联想补全，
新标签自动入库，标签库统一维护。

作品标签库：
  ▪ 每个分类独立维护作品标签
  ▪ 支持标签分组（如：题材、风格、受众等）
  ▪ 编辑时输入联想自动补全
  ▪ 下拉列表按分组浏览选择
  ▪ 新标签自动追加到标签库

人物标签库：
  ▪ 独立于作品标签的人物标签体系
  ▪ 按分组管理人物属性标签
  ▪ 支持标签重命名和分组调整
  ▪ 批量管理标签库
  ▪ 删除标签自动解除作品关联

收藏夹
------

灵活的收藏夹功能，让你按主题、心情或任意维度组织你的作品收藏。
收藏夹跨分类工作，可以把不同类型的作品放在一起。

  ▪ 创建无限个收藏夹，每个收藏夹可自定义名称和介绍说明
  ▪ 收藏夹封面自动使用第一个作品的海报，视觉直观
  ▪ 支持从作品详情页一键添加到多个收藏夹
  ▪ 收藏夹内作品卡片与主视图样式一致，副标题显示作品元数据
  ▪ 右键菜单快速编辑收藏夹名称、介绍或删除收藏夹
  ▪ 删除作品时自动清理收藏夹中的引用，数据一致
  ▪ 导入导出完整保留收藏夹结构与内容

搜索与筛选
----------

强大的搜索和筛选功能，帮助你在大量作品中快速找到目标。

  ▪ 全文搜索：支持作品名称、别名、简介等多字段模糊搜索
  ▪ 分类筛选：顶部分类栏一键切换，快速浏览不同类型作品
  ▪ 标签筛选：按标签维度筛选，支持多标签组合过滤
  ▪ 进度筛选：按进行中、已完成、搁置、未开始状态筛选
  ▪ 排序功能：按名称、添加时间、评分等多种方式排序
  ▪ 视图切换：网格视图与列表视图自由切换，按需选择

数据与安全
----------

所有数据保存在本地，格式开放透明，你对自己的数据拥有完全控制权。

数据存储位置：
  数据默认保存在 %APPDATA%\anime-media-manager\data\ 目录下，
  以 JSON 格式存储每个分类的作品数据，图片文件存储在 images 目录中。

技术特性
--------

【纯本地运行】
  无需联网，不上传任何数据，所有操作在本地完成，隐私安全有保障

【开放数据格式】
  JSON 格式存储，可直接编辑、版本管理，不会被封闭格式锁定

【缩略图缓存】
  自动生成缩略图，加载更快更流畅，支持动图原图保留

【自定义扩展】
  支持自定义字段、自定义标签分组，按需打造专属管理体系
