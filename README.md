# 本地动漫作品管理 —— 使用说明

一个面向动漫、漫画、影视、游戏等本地媒体资源的**桌面管理工具**。它是一个本地运行的桌面程序（Electron 应用），无需联网，所有数据保存在本机，用于对你在本地文件夹里收藏的作品进行分类、管理、浏览和播放。

---

## 一、核心功能一览

| 功能 | 说明 |
| --- | --- |
| 多分类管理 | 番剧、漫画、电视剧、短剧、漫剧、动态漫、游戏、MMD、3D、2D、AV 等分类 |
| 卡片 / 列表双视图 | 作品以网格卡片或列表两种方式展示 |
| 全文覆盖搜索与筛选 | 按名称搜索，并按各分类字段精确筛选 |
| 完成状态与待处理标记 | 未开始 / 进行中 / 已完成 / 搁置中 / 待处理 |
| 作品详情页 | 封面、资料、文件列表（图片 / 视频 / 音频 / 文本） |
| 章节式浏览 | 章节、卷、特典、额外章节结构化管理与连读 |
| 内嵌播放器 | 底部音频播放器，支持歌词、均衡器、桌面歌词同步歌词 |
| 漫画阅读器 | 独立阅读器（ComicReader）浏览 CBZ / 文件夹漫画 |
| 标签库与人物库 | 集中管理标签和人物资料 |
| 字典管理 | 作者、出版社、译者、分类、标签、版本 / 格式字典 |
| 界面主题 | 深色 / 浅色模式切换 |
| 安全模式 | 一键显示 / 隐藏敏感内容 |
| 数据本地化 | 所有数据与缓存保存在本机 |

---

## 二、界面组成

程序打开后整体分为四个区域：

### 1. 顶部标题栏
最顶上一行，包含：
- **敏感内容开关**：显示 / 隐藏敏感内容
- **日志**：查看程序运行日志（报错排查用）
- **标签库 / 人物库**：快捷打开两个库的编辑面板
- **最小化、最大化、关闭**：窗口控制按钮

### 2. 左侧分类栏（侧边栏）
列出所有作品分类：所有作品、番剧、漫画、电视剧、短剧、漫剧、动态漫、游戏、MMD、3D作品、2D、AV 等。每个分类右侧显示该分类的数量。点击即可切换当前浏览的分类。侧边栏底部有**设置**按钮，可折叠侧边栏或进入全局设置。

### 3. 顶部工具栏（主内容区上方）
- **搜索框**：输入关键词即可在全库或当前分类中搜索作品
- **首页**：返回首页
- **待处理**：一键筛选出"完成状态为待处理"的作品
- **收藏**：筛选出已收藏的作品
- **悬停显示图标**：切换卡片上鼠标悬停时是否显示操作图标
- **更新图片缓存**：重建或清理图片缓存
- **网格视图 / 列表视图**：切换作品的展示方式
- **筛选**：按当前分类的字段进行条件筛选
- **＋ 添加作品**：新建一条作品记录

### 4. 主内容区
根据当前所选分类和视图显示作品卡片网格、列表，或单个作品的详情页、编辑页、标签库、人物库。

---

## 三、作品分类（板块）说明

程序把作品划分成多个分类，每个分类有不同的字段用来描述作品：

- **番剧 / 电视剧 / 短剧 / 漫剧 / 动态漫**：影视类，含集数、导演、配音、放送状态等信息
- **漫画**：漫画类，额外支持"卷"（第X卷）与"话"（第X话）结构、篇幅、颜色等
- **游戏**：游戏类，含平台、开发商、发售日期等
- **MMD / 3D / 2D**：用相关工具制作的作品
- **AV**：成人向内容，受顶部"安全模式"开关控制显示

每个分类编辑时都会呈现对应的字段；字典类字段（作者、出版社、分类、标签、版本格式、配音等）需要在"字典管理"里维护后才能在编辑界面下拉选填。

---

## 四、添加与编辑作品

### 添加作品
点击顶部工具栏的 **＋ 添加作品**，进入编辑界面。填写名称、选择分类、上传封面、填写各项资料后点"保存"即可。所选分类不同，出现的字段也不同。

### 编辑作品
在网格卡片上双击（或通过卡片菜单、列表项）进入详情页，点击"编辑"进入编辑界面修改。

### 图片选择
点击图片字段的"选择图片"，会从本地挑选图片，程序自动把图片缩放、转成 WebP 并缓存到本地（`data/images` 目录），无需你管理原始文件。选择后保存即可。

### 删除作品
在卡片或列表上使用右键菜单 / 操作按钮删除。删除会同时清理该作品的图片缓存。

---

## 五、完成状态与待处理标记

每个作品都可以设置一个"完成状态"，右键卡片 → **完成状态** 子菜单中选择：

| 状态 | 含义 |
| --- | --- |
| 未开始 | 尚未开始观看 / 游玩 |
| 进行中 | 正在进行 |
| 已完成 | 已经看完 / 玩完 |
| 搁置中 | 暂时搁置 |
| **待处理** | 表示作品存在异常或待处理事项 |

选择 **待处理** 状态后，该作品卡片会自动显示**边框**，用于醒目地标记需要你重点跟进的作品。

你还可以点击顶部工具栏的 **待处理** 按钮，一键筛选出所有标记为"待处理"的作品，统一处理。

---

## 六、卡片视图与列表视图

### 网格视图（卡片）
以一张张封面卡片展示作品，卡片上显示：
- 封面图片
- 作品名称
- 副标题信息（不同分类展示不同：游戏显示"发售日期, 开发商"、漫画显示"发售日期, 连载状态"等）

鼠标悬停卡片会显示操作图标（可通过工具栏"悬停显示图标"开关控制），卡片可有轻微缩放效果。

### 列表视图
以表格式列表展示，可点击表头按 **名称 / 日期 / 状态 / 最近添加** 排序。

---

## 七、搜索与筛选

- **搜索**：在顶部搜索框输入文字，实时过滤当前分类下的作品，支持按名称匹配。
- **筛选**：点击"筛选"打开筛选面板，按当前分类的字段做精确筛选（例如仅看漫画中某个篇幅、某个颜色，或仅看某状态的作品）。筛选面板会根据当前分类动态变化。

---

## 八、作品详情页

点击作品进入详情页，集中查看和操作一部作品的完整内容：

### 1. 基本信息区
封面大图 + 名称 + 各项资料（作者、出版社、标签、状态、简介等）。简介支持**富文本**，可插入图片、视频等内容。

### 2. 文件列表区
展示作品对应本地文件夹的目录结构，并支持在程序内直接浏览：
- **图片**：点击可预览
- **视频 / 音频**：点击可播放（音频直接进入底部播放器）
- **.txt 文件**：点击可打开并在线编辑

### 3. 章节结构区（漫画等分类）
对于漫画类作品，会按文件夹 / 文件自动识别并分成：
- **章节**（第X话）
- **卷**（第X卷）
- **特典**
- **额外章节**

支持跨章节、跨卷的连续阅读（阅读器 / 图片连看）。

### 4. 特典与额外章节说明
- **特典**：作品下的 `特典/` 文件夹，子文件夹以"作品名"命名的特典会被识别为该作品的专属特典。
- **额外章节**：用于存放番外、花絮等正片之外的额外内容。

---

## 九、音乐与音频播放器（底部）

详情页中播放任意音频文件后，底部会固定显示一条**播放器栏**（始终位于程序最下方），提供：

- 封面、标题、进度条与时间
- **上一首 / 播放暂停 / 下一首**（播放暂停使用圆形图标，居中对齐）
- **音量**与**静音**
- **播放模式**（顺序 / 循环 / 单曲循环 / 随机）
- **播放列表**：点击右侧滑出播放列表面板，可"＋ 添加文件"、移除、切换曲目
- **音频设置**：选择输出设备、切换声道、预设均衡器
- **桌面歌词 / 歌词锁定**：显示桌面歌词，并可锁定歌词窗口位置

播放器栏左侧封面区域：鼠标悬停显示双向上箭头，点击打开完整的**播放界面**；播放界面右侧有向下的"收起"箭头，点击返回迷你播放栏。

---

## 十、标签库与人物库

- **标签库**：集中管理全部自定义标签。标签可以带说明文字，说明中支持 `[img]`、`[video]` 标记，在详情页标签悬停气泡中显示为内联图片和视频图标，方便你用截图 / 短视频注解某个标签的含义。
- **人物库**：集中管理人物资料（名称、头像、介绍等）。人物卡片统一图片高度为 200px、按比例宽度、互不重叠。

---

## 十一、局部变量维护与字典管理

作者、出版社、译者、分类、标签、版本 / 格式这些"字典型"数据**必须**先在字典管理中手动添加，才能出现在编辑界面的下拉列表里。编辑作品时不会自动把新输入的价值保存进字典。

---

## 十二、界面主题与显示设置

- **深色 / 浅色模式**：可在设置中切换。浅色模式下界面与卡片采用浅色配色，深色模式为默认深色界面。图片显示保持完整一致。
- **悬停显示图标**：控制卡片悬浮时是否显示操作图标。

---

## 十三、安全模式

顶部标题栏的"眼睛 / 敏感内容"开关：开启时显示成人向（如 AV 分类）内容，关闭时隐藏这些内容。适合在共享场合快速隐藏。

---

## 十四、数据存储位置

程序的数据与缓存均保存在本机，例如（Windows 用户目录下）：
- 图片缓存：`C:\Users\<用户名>\AppData\Roaming\anime-media-manager\data\images\`
- 数据库与配置：位于同一 `anime-media-manager` 数据目录下

> 提示：删除程序时如需彻底清空，可同时删除该数据目录。
