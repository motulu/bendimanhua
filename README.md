# 本地动漫作品管理
一款桌面端本地动漫/媒体作品管理工具，帮助你高效地整理、分类和浏览本地收藏的动漫与媒体资源。

## 核心功能
### 📂 多板块分类管理
支持按作品类型分板块管理，每个板块拥有独立的数据库和字段配置：

- 番剧 / AI漫剧 / 动态漫 / 3D作品 / 2D — 动画类作品
- 游戏 / MMD / AV / MV — 其他媒体类型
- 声音作品 — ASMR、广播剧等音频作品
- 网站存储柜 — 收藏常用网站链接，支持分组管理
### 📝 丰富的作品信息
每部作品可记录：中文名、原名、别名、作者、出版社、译者、标签、人物、故事弧、集数、页数、上映日期、状态、评分、备注等，字段随板块自动适配。

### 🎵 内置播放器
- 支持直接从作品详情页打开音频/视频文件播放
- 播放栏嵌入主界面底部，支持迷你模式和完整播放界面
- 声道切换、均衡器预设、输出设备选择
- 播放列表管理、桌面歌词
### 🔍 强大的搜索与筛选
- 全文搜索，支持 /字段/数据 精确搜索语法
- 多条件筛选面板（按标签、人物、状态、日期等）
- 支持标签别名搜索
### 🎨 双主题与视图切换
- 深色/浅色两种主题，一键切换
- 网格视图（封面卡片）和列表视图
- 侧边栏可折叠，键盘快捷键支持
### 🏷 标签库与人物库
- 独立的标签和人物管理系统
- 支持标签别名、人物标签关联
- 按标签/人物快速筛选作品
## 技术特点
- 纯本地运行 ：所有数据存储在本地，无需网络
- 便携版 ：单文件 exe，无需安装，解压即用
- 数据独立 ：各板块数据分离存储，互不干扰
